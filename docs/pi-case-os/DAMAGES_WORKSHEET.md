# PraxiumLaw — Damages Worksheet (Data Capture)

A structured way to **capture** every element of damages so nothing is missed in the [demand](articles/39-demand-letter-drafting.md) and [disbursement](articles/25-disbursement-sheet-preparation.md). **This is data collection, not valuation.** It does not calculate or advise what a case is "worth" — that is an [attorney judgment](GAP_ANALYSIS_AND_ROADMAP.md). See [`DISCLOSURE.md`](./DISCLOSURE.md).

## Non-economic damages (general damages) — capture facts, not a number

Record the **evidence** that supports pain/suffering and loss of enjoyment; do **not** compute a value here.

- Injury list and severity; permanency/impairment rating (if any)
- Treatment burden (procedures, injections, surgery, therapy duration)
- Functional limitations / activities of daily living affected
- Duration of symptoms; consistency of reporting
- Impact on work, family, hobbies (with corroboration)
- Photos, journals, witness statements

## Coverage & offsets (context for the attorney)

- Available limits: 3P liability, [UM/UIM](articles/49-um-uim-and-first-party-claims.md), MedPay/PIP ([33](articles/33-auto-insurance-coverage-reference.md))
- Comparative-fault considerations (jurisdiction — see [`JURISDICTION_MATRIX.md`](./JURISDICTION_MATRIX.md))
- Liens/claims that reduce net ([29](articles/29-health-insurance-subrogation.md), [53](articles/53-non-medical-liens-and-claims.md))

## Output

A complete, sourced damages picture the **attorney** uses to value and negotiate the case. Every line should trace to a document in the file.

## Guardrail

The worksheet **captures and organizes**; it must not present a settlement value, multiplier, or range to the client. Valuation and any figure communicated to the client are **attorney decisions**.
