# Records Retrieval & Vendor Management

**Category:** Medical Record Tracking / Operations
**Recommended procedure** — cross-reference against your firm's policy and jurisdiction before use.
**White-label:** Any firm. See [`../DISCLOSURE.md`](../DISCLOSURE.md).
**References:** [`../REFERENCES.md`](../REFERENCES.md)

---

## Purpose

Cases live or die on complete records and bills. This SOP standardizes how the firm requests, tracks, and follows up on records — in-house and via retrieval vendors/portals — so the [demand](39-demand-letter-drafting.md) isn't archaeology and nothing is missing at [disbursement](25-disbursement-sheet-preparation.md).

## Request standards

- Use a **valid HIPAA authorization** for each provider; track expiration ([firm HIPAA](46-firm-hipaa-and-data-security.md)).
- Send the right request per provider ([medical LOR workflow](21-medical-lor-workflow.md)); request **records and bills** and a **certificate of records** ([COR](20-certificate-of-records.md)) where needed.
- **Minimum necessary**; request the correct date range (crash-related; add prior records only when the strategy calls for it).

## Retrieval channels

- **In-house** letters/fax/portal for routine providers.
- **Provider portals / retrieval services** (e.g., records-exchange platforms) for hospitals and high-volume providers — faster, trackable. If a vendor handles PHI on the firm's behalf, get a **BAA** ([firm HIPAA](46-firm-hipaa-and-data-security.md)).
- Track **cost** of each request as a case expense so it flows to [disbursement](25-disbursement-sheet-preparation.md).

## Tracking & follow-up (the discipline)

- Maintain a **records tracker** per matter: provider, request date, type, due date, status, received date.
- Task a **specific** provider follow-up (never "everyone"), and task **yourself** to check back on a set cadence (e.g., weekly) — a completed request task ≠ documents arrived ([demand prep discipline](09-demand-prep-checklist.md)).
- Escalate stale requests; some providers/records companies are chronically slow — build in buffer before demand/lit deadlines.

## Completeness check

Before demand: every provider in the [meds tab](08-meds-tab-and-record-hygiene.md) has matching **records and bills**, imaging reports attached, and CORs where required. Flag gaps and resolve them, don't paper over them.

## Attorney / case-manager gate

Which records to request (especially **prior** records) and how much to spend on retrieval are supervised decisions. Protect PHI throughout ([redaction](19-redaction-checklist.md), [firm HIPAA](46-firm-hipaa-and-data-security.md)).
