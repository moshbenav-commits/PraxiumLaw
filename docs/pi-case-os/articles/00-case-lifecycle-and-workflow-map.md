# Case Lifecycle & Workflow Map

**Category:** Master workflow
**Recommended procedure** — cross-reference against your firm's policy and jurisdiction before use.
**White-label:** Any firm. See [`../DISCLOSURE.md`](../DISCLOSURE.md).
**References:** [`../REFERENCES.md`](../REFERENCES.md)

---

## Purpose

The single map for running a personal-injury matter start to finish. Each phase lists what must happen, the gate to advance, and the article with the detailed steps. Use it as the backbone for the [case-management setup](36-case-management-system-setup.md) phases.

## End-to-end phases

| # | Phase | Do this | Gate to advance | Article(s) |
|---|-------|---------|-----------------|-----------|
| 1 | **Lead & qualify** | Respond fast; screen for SOL, liability, coverage, injuries; conflict check | Passes intake criteria; attorney accepts | [35](35-lead-intake-and-signup-operations.md), [13](13-conflict-check-and-related-cases.md), [33](33-auto-insurance-coverage-reference.md) |
| 2 | **Sign up** | Written retainer/fee agreement, HIPAA, intake forms; open matter & file | Signed agreement on file | [23](23-intake-forms-and-signature-packet.md), [01](01-intake-needs-list.md), [17](17-in-office-intake-coaching.md) |
| 3 | **Open claims** | 1P & 3P letters of representation day one; confirm coverage/limits | Claims opened, adjusters logged | [04](04-opening-3p-and-1p-claims.md), [14](14-client-insurance-script.md), [15](15-policy-limits-and-claimants.md) |
| 4 | **Property damage** | Resolve vehicle/PD before any bodily-injury release | PD handled or tracked | [03](03-property-damage-liability-timing.md) |
| 5 | **Treatment mgmt** | Coordinate care, gaps/MRI timing, records hygiene, compliance coaching | Treatment progressing, records tracked | [05](05-treatment-gaps-and-mri-timing.md), [08](08-meds-tab-and-record-hygiene.md), [12](12-chiro-follow-up-color-codes.md), [16](16-treatment-compliance-coaching.md), [21](21-medical-lor-workflow.md), [24](24-medical-documents-reference.md) |
| 6 | **Case review** | 30-day / periodic reviews; call cadence; social-media caution | Reviews current | [07](07-thirty-day-case-review.md), [11](11-client-call-cadence.md), [06](06-social-media-and-subrosa.md) |
| 7 | **Records & demand prep** | Reconcile all bills/records; certificates of records; redact | Demand package complete | [09](09-demand-prep-checklist.md), [20](20-certificate-of-records.md), [19](19-redaction-checklist.md), [18](18-document-taxonomy.md) |
| 8 | **Demand** | Draft and send the demand; calendar the response | **Attorney approves send** | [39](39-demand-letter-drafting.md) |
| 9 | **Negotiate** | Log offers/counters; scenario the net | **Attorney sets authority** | [10](10-settlement-calculator-scenarios.md), [26](26-reduction-requests-and-negotiation.md) |
| 10 | **Litigate (if needed)** | File suit when demand stalls or SOL nears; transfer notices | **Attorney decision** | [31](31-litigation-handoff-and-management.md), [22](22-transfer-to-litigation.md) |
| 11 | **Special approvals** | Minor's compromise (court approval); mass-tort registry if applicable | Court/administrator approval | [30](30-minors-compromise-and-court-approval.md), [32](32-mass-tort-intake-and-management.md) |
| 12 | **Settle** | Confirm final offer; releases (attorney-reviewed); resolve liens | **Attorney authorizes** | [27](27-settlement-and-disbursement-workflow.md), [29](29-health-insurance-subrogation.md) |
| 13 | **Disburse** | Disbursement sheet, reductions, trust checks, client payout | **Attorney/trust approval** | [25](25-disbursement-sheet-preparation.md), [26](26-reduction-requests-and-negotiation.md), [27](27-settlement-and-disbursement-workflow.md) |
| 14 | **Close out** | Reconcile trust, satisfy liens, deliver documents, retain file | Trust reconciled; file retained | [40](40-file-closeout-reconciliation-and-retention.md) |

**Exit at any phase:** if coverage fails or the client is unreachable, follow [client termination & attorney liens](28-client-termination-and-attorney-liens.md).

## Case types that branch from this spine

- **Auto PI** — the default path above.
- **Premises liability / slip-and-fall** — different liability proof; see [41](41-premises-liability-slip-and-fall.md).
- **Workers' compensation** (or a comp-plus-third-party case) — separate system and liens; see [42](42-workers-compensation-coordination.md).
- **Minor impact / soft tissue (MIST)** — valuation and proof strategy; see [43](43-mist-minor-impact-soft-tissue.md).
- **Mass tort** — campaign criteria and registry; see [32](32-mass-tort-intake-and-management.md).

## Attorney gates (never bypass)

Case acceptance · demand send · settlement authority · reduction percentages · trust disbursement · minor's-compromise process · withdrawal/lien. Staff prepare; the attorney approves.
