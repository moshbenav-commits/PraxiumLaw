# Settlement Calculator Scenarios and the Negotiations Tab

**Category:** Settlement Negotiation Guidelines  
**Recommended procedure** — cross-reference against your firm's policy and jurisdiction before use.  
**White-label:** Any firm. See [`../DISCLOSURE.md`](../DISCLOSURE.md).  
**References:** [`../REFERENCES.md`](../REFERENCES.md)  
**Audience:** Case managers (data entry); attorneys (reduction decisions)

---

## Log every offer

When an offer arrives in writing (or is otherwise confirmed), enter it on the **Negotiations tab**:

- Amount
- Date
- Direction (insurance → plaintiff)
- Adjuster / carrier notes
- Save or screenshot the offer letter into Docs

Do this for each claimant when multiple clients share a loss.

## Build scenarios from Meds

The settlement calculator only works if Meds is current. Copy each provider and balance into the scenario. Training shows staff entering providers line by line from Meds, then asking the attorney for **percentages or flat reductions**.

## Multiple scenarios

Create a scenario for the **initial offer** and additional scenarios for improved offers. The point is to show the client **net in pocket** under different reduction assumptions — not a single static spreadsheet.

Providers may refuse an expected reduction (for example not agreeing to 50%). Re-run scenarios when reduction assumptions change.

## Role split

| Role | Action |
|------|--------|
| Case manager / support | Enter offers, populate provider balances from Meds |
| Attorney | Set reduction percentages or flat amounts; approve client-facing numbers |

PraxiumLaw should enforce this split so staff cannot publish net-to-client figures without attorney inputs.
