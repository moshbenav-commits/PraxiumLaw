# Meds Tab Hygiene and Medical Record Tracking

**Category:** Medical Record Tracking Protocol  
**Recommended procedure** — cross-reference against your firm's policy and jurisdiction before use.  
**White-label:** Any firm. See [`../DISCLOSURE.md`](../DISCLOSURE.md).  
**References:** [`../REFERENCES.md`](../REFERENCES.md)  
**Audience:** Case managers, records staff

---

## The Meds tab is the spine of the file

Demand prep training treats a wrong Meds tab as an organizational failure that spreads: wrong contacts, wrong balances, wrong settlement calculator, wrong reductions, unpaid lienholders.

**Rule:** Every provider the client treated with must appear on Meds, and Meds must match the documents in the file.

## Contact hygiene

- Use the **clinic / entity** name, not a random staff or doctor name that creates duplicates
- Merge duplicates instead of creating “David Lewis” when the provider is a clinic entity
- Enter specialty (chiro, pain management, hospital, pharmacy, etc.)
- Enter first date of treatment and lien holder when applicable
- Put case manager initials on entries so generated letters show the correct staff

## File naming

Keep names short so systems do not break:

- `MR` — medical records
- `B` — bills
- `FE` — futures estimate (include amount and date)

Use **hashtags** (provider name, anesthesia, etc.) because folder structures may be limited.

## While the client is still treating

Do **not** order full records every month. Use **lien balance verification** by phone or letter. Full medical LORs are for demand prep or missing providers — and they cost money.

## Provider-specific portals

Some providers only release records through portals such as **ChartSwap**. Check the doctor referral list **before** sending a standard LOR and waiting a week for a rejection.

## Futures estimates

Save injection/surgery estimates as `FE`. If later bills do not reconcile to the FE, request updated records and bills.

## High-Tech letter

For invoices **$100 and above**, training directs use of the **High-Tech letter** (with the signed HIPAA page) when ordinary requests fail — and to use it going forward as the default for those requests.
