# PraxiumLaw — Jurisdiction Matrix (Template)

Personal-injury rules vary by state. This is a **template and methodology** for building your firm's own state matrix — **not** a substitute for confirming current law. **Every cell must be verified with counsel for the operating state** before use. Rules change. See [`DISCLOSURE.md`](./DISCLOSURE.md) and public [`REFERENCES.md`](./REFERENCES.md).

> Do not treat any example below as legal advice or as current. Fill and maintain this per state with a licensed attorney.

## Columns to track (per state)

| Column | What to capture |
|--------|-----------------|
| **PI statute of limitations** | Years; claim-type variations (MVA, med-mal, gov't claims); tolling for minors/discovery |
| **Government-claim deadlines** | Notice-of-claim periods (often much shorter) |
| **Comparative/contributory fault** | Pure comparative / modified (50% or 51% bar) / contributory |
| **UM/UIM structure** | Setoff/gap vs. excess/add-on; stacking allowed?; consent-to-settle rule ([49](articles/49-um-uim-and-first-party-claims.md)) |
| **No-fault / PIP vs. tort** | Threshold to step outside no-fault, if any |
| **Med-pay rules** | Availability; subrogation/anti-subro |
| **Health-plan subrogation** | Made-whole default; anti-subrogation statutes ([29](articles/29-health-insurance-subrogation.md)) |
| **Hospital-lien / provider-lien statutes** | Existence and caps |
| **Minor-settlement approval** | Court-approval threshold; GAL rule; blocked-account rules ([30](articles/30-minors-compromise-and-court-approval.md)) |
| **Solicitation / capping** | Anti-solicitation/runner statute; penalties ([44](articles/44-referral-sources-and-marketing-compliance.md)) |
| **Fee rules** | Contingency-fee caps/tiers; written-fee requirement (Rule 1.5) |
| **Trust/IOLTA specifics** | State recordkeeping/retention (Rule 1.15) ([45](articles/45-trust-accounting-and-reconciliation.md)) |
| **Damages caps** | Any non-economic/punitive caps |
| **Litigation-funding rules** | Registration/disclosure (e.g., funding statutes) |
| **E-sign / RON** | UETA specifics; remote online notarization availability |

## Illustrative notes (verify — do not rely as current)

These are **orientation only**, drawn from general public sources; confirm before use:

- **SOL:** a 2- or 3-year PI window is most common in the U.S.; a few states range 1–6 years, and minors are often tolled. ([SOL overview](https://www.mwl-law.com/resources/statute-limitations-50-states/))
- **Capping/solicitation:** some states criminalize paying non-lawyers for client referrals and let an improperly solicited client void the fee agreement (e.g., Nevada NRS 7.045). ([Nevada Lawyer](https://nvbar.org/wp-content/uploads/NevadaLawyer_Sept2022_Unlawful-Solictation.pdf))
- **Health-plan subrogation:** ERISA "made-whole" is a default clear plan language can override (*McCutchen*). ([ERISA subro](https://www.buchanandisability.com/erisa-health-care-subrogation-reimbursement-and-overpayments/))
- **Litigation funding:** many states now register/disclose commercial funders (e.g., Nevada NRS Ch. 604C). ([funding overview](https://iclg.com/practice-areas/lending-and-secured-finance-laws-and-regulations/21-an-overview-of-litigation-funding))
