## Excluded from extraction

- Password files, job offers, timesheets, payroll, personal contacts
- Real-estate / MLS / Transaction Desk modules mixed into the same archive
- Admin-only (password managers, hiring tools)
- Client-identifying case examples in transcripts (anonymized or omitted)

## Anonymization applied

Firm names, attorney names, and staff personal names from source materials were replaced with role labels (`the attorney`, `the case manager`, `the intake specialist`, `the firm`) in published outputs. Provider names/addresses, bank/court contacts, phone numbers, and state-specific statute citations from the source SOPs were **dropped, not carried into** published articles. Source folder names on disk may still reflect historical labels; published PraxiumLaw docs do not.
