## PI case phases (training pipeline)

`Intake` → `Treating` → `Record gathering` → `Demand` → `Waiting for offer` → `Counter` / `Supplement` → `Settlement / disbursement` → (`Minor's compromise`) → `Litigate` / `Drop` / `Closed`

**PraxiumLaw today** uses PI phase pipeline on personal injury matters (`Pipeline` tab + PI kanban on `/matters`). Generic matter statuses remain for non-PI practice areas.
