# Training Guide — Support Staff / Clerical

**PraxiumLaw role:** `staff`  
**Reports to:** Case manager · Office manager

---

## Purpose

You keep the **paper and digital file moving**: scan/index documents, mail, data entry support, calendar coordination, and client logistics — without giving legal advice or speaking to adjusters on injuries.

---

## What you own

| Task | Notes |
|------|-------|
| Scan and upload documents | Correct **taxonomy** on every file |
| Mail / certified letters | LOR, lien notices — templates attorney-approved |
| Index naming | MR, B, FE conventions per firm SOP |
| Calendar support | Appointments, SOL reminders visible on `/calendar` |
| Copy / fax / file organization | Physical + PraxiumLaw Documents tab |
| Client logistics | ID copies, declarations page copies, portal upload help |
| Expense receipts | Police report fees, copy fees — for disbursement |

---

## Document taxonomy (required)

Every inbound item gets one type — see [`../articles/18-document-taxonomy.md`](../articles/18-document-taxonomy.md).

**Medical uploads** use naming MR / B / FE — [`../articles/24-medical-documents-reference.md`](../articles/24-medical-documents-reference.md):

| Code | Meaning |
|------|---------|
| MR | Medical records |
| B | Bills |
| FE | Futures estimate |

**Intake uploads** (signed packet, ID, cards): type **Intake** — catalog: [`23-intake-forms-and-signature-packet.md`](../articles/23-intake-forms-and-signature-packet.md).

---

## What you do NOT do

- Open or negotiate claims with adjusters on injuries  
- Set reduction amounts or settlement numbers  
- Send demand packages  
- Give clients legal strategy  

Escalate to case manager or attorney.

---

## PraxiumLaw — wired today

| Action | Where |
|--------|-------|
| Upload with **required taxonomy** | Matter → **Documents** → Upload (type + MR/B/FE/COR for medical) |
| Re-tag / filter by type | Documents tab table |
| Redaction checklist + carrier OK | Documents tab → **Redact pending** on medical / auto insurance |
| Firm-wide doc list | `/documents` |
| Magic-link client upload | `/upload/:token` (client-facing — taxonomy not yet on portal) |
| Tasks assigned to you | `/tasks` |
| Team chat | `/chat` |
